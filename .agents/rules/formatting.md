# Formatting Guidelines

Strict formatting: Do NOT use emojis or icons anywhere in code, comments, commit messages, or technical documentation. Use plain Markdown and plain text only.

- Do not use emojis or icons in source code (Python, XML, JavaScript, etc.).
- Do not use emojis or icons in comments, docstrings, or code annotations.
- Do not use emojis or icons in Git commit messages.
- Do not use emojis or icons in technical documentation, specifications, or markdown notes.
- Always use plain Markdown and plain text.
